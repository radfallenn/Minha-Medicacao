# Minha Medicação

Aplicativo Android para controle diário de medicamentos.

## Recursos atuais
- Rotina diária de medicamentos
- Registro de doses tomadas / não tomadas
- Histórico
- Controle de estoque
- Banco local IndexedDB
- Backup e restauração em JSON
- Edição de medicamentos
- Lembretes no app

## APK
O GitHub Actions compila automaticamente um APK de teste a cada atualização do repositório. Abra **Actions > Build APK**, entre na execução mais recente e baixe o artefato **Minha-Medicacao-APK**.

> Este aplicativo serve para organização da rotina. Ele não substitui orientação médica nem decide ajustes de dose.
